¿Cómo lo hice?

Seis etapas, de la API al tablero publicado. Sin pasos inventados: solo las herramientas y decisiones que están detrás del visual.

  1. 01

    Fuentes

    Datos abiertos, una API y un estándar

    Migración Colombia publica las entradas de extranjeros en datos.gov.co. La API de Socrata entrega la tabla; la ONU aporta los códigos M49 para agrupar por país y región. La licencia es CC BY-SA 4.0 y el corte de la fuente es el 20/08/2026.

    • datos.gov.co
    • API Socrata
    • UN M49
    • 181.186 filas
  2. 02

    Extracción y limpieza

    Cuatro páginas, una tabla consistente

    Descarga vía API en cuatro páginas de 50.000 filas. En Power Query: tipado de columnas, renombrado de Total a Viajeros, unión con la dimensión M49 por código y revisión de nulos y códigos residuales. La columna Indefinido está vacía y no aporta al modelo.

    • 4 páginas
    • Normalización por M49

  4. 04

    Cálculos y lógica de negocio

    Tres medidas que sostienen los KPIs

    El total suma Viajeros (Femenino + Masculino), no la columna Total original. El año pico se calcula con TOPN y MAXX; los países emisores se cuentan sobre la dimensión M49. La diferencia con la fuente se documenta en la sección de calidad.

    Ver las medidas DAX 
    total viajeros =
SUM('Entradas_de_extranjeros_a_Colombia_20261124'[Viajeros])

año pico =
MAXX(
    TOPN(
        1,
        VALUES('Entradas_de_extranjeros_a_Colombia_20261124'[Año]),
        [total viajeros],
        DESC
    ),
    'Entradas_de_extranjeros_a_Colombia_20261124'[Año]
)

paises emisores =
CALCULATE(
    DISTINCTCOUNT('UNSD — Methodology'[Country or Area]),
    'Entradas_de_extranjeros_a_Colombia_20261124'
)

Calidad del dato

Lo que encontré al revisar la fuente y cómo lo traté. Es la parte que no se ve en el tablero, pero la que permite confiar en él.

Hallazgos de calidad del dato y su tratamiento
Hallazgo Magnitud Tratamiento
Códigos residuales 4 códigos · 26.515 entradas 99999 (24.301) + No Aplica (2.214). Se reportan aparte; no se asignan a un país.
Nombres duplicados 24 códigos con 2 variantes Diferencias de mayúsculas (“de” vs “De”, “y” vs “Y”). Se unifican por código M49.
Total vs Femenino + Masculino 1.275 filas · 2.051 entradas El tablero usa Femenino + Masculino; la fuente reporta Total. Se documenta la diferencia.
Columna “Indefinido” 100 % vacía No aporta al modelo y se excluye.
2026 parcial Enero–junio · 2.430.484 Se marca en el visual; no se compara con años completos.
Kosovo (901) 298 entradas No está en M49. Se reporta aparte del conteo de países.

La fuente suma 44.928.340 con la columna Total; el tablero suma 44.926.183 con Femenino + Masculino. La diferencia de 2.157 incluye 2.051 entradas de filas donde Total ≠ F+M y 106 pendientes de revisar en el refresh.

Qué no responde

Un tablero también se define por lo que deja fuera. Estas son las preguntas que los datos no permiten contestar con honestidad.

  • No son personas únicas. Cada fila es una entrada registrada; una misma persona puede cruzar varias veces.
  • Nacionalidad no es residencia. El país corresponde a la nacionalidad, no al lugar desde donde llegó el viajero.
  • 2026 está incompleto. Solo hay enero–junio. La comparación justa es −2,7 % vs ene–jun 2025, no contra años completos.
  • La fuente es semestral. El tablero no se actualiza solo y no promete tiempo real.
  • Cinco códigos no tienen región M49. Kosovo y cuatro residuales se reportan aparte.
  • No explica causas ni motivo de viaje. No hay edad, aeropuerto, tipo de visa ni intención de viaje.

Reproducibilidad

La tabla completa se puede traer con cuatro solicitudes a la API. El endpoint es público; no requiere credenciales.

API Socrata · 96sh-4v8d 4 páginas · 50.000 por página 
https://www.datos.gov.co/resource/96sh-4v8d.json?$limit=50000&$offset=0&$order=:id
https://www.datos.gov.co/resource/96sh-4v8d.json?$limit=50000&$offset=50000&$order=:id
https://www.datos.gov.co/resource/96sh-4v8d.json?$limit=50000&$offset=100000&$order=:id
https://www.datos.gov.co/resource/96sh-4v8d.json?$limit=50000&$offset=150000&$order=:id

$order=:id mantiene la paginación estable. La API acepta hasta 50.000 filas por solicitud; la última página trae 31.186. La fuente se actualiza: el conteo puede cambiar con el tiempo. Consulta de referencia: 24/11/2026.
